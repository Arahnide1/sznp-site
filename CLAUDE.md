# СЗНП Сибирь — заметки для работы над сайтом

## Контекст
- Сейчас сайт статичный (HTML/CSS/JS без сборки), публикуется через GitHub Pages.
- **Сайт будет переноситься на WordPress.** Всё, что делаем сейчас, должно легко переходить в тему WP.
- Наша часть работы — динамичный дизайн (вид, анимации, расположение). Бэкенд, формы, юридические страницы и каталог как данные — дело разработчиков.

## Как писать код с учётом переезда на WordPress
- Тексты держим в HTML, а не в JS: их проще перенести в шаблоны и редактор WP.
- Стили держим в модулях `css/*.css` и через переменные из `css/tokens.css` (цвета, шрифты, размеры). Не писать значения «в лоб» и не использовать inline-стили, где можно обойтись классом.
- Блоки страниц делаем самодостаточными (секция = один блок со своими классами), чтобы потом превращаться в блоки/шаблонные части темы.
- Картинки подключаем обычными путями из `img/`; не завязываться на структуру папок в JS.
- Переключатель RU/EN сейчас сделан на `data-i18n` и `i18n/en.js`. В WP его заменят на плагин мультиязычности (Polylang/WPML), поэтому ключи `data-i18n` не удалять и не переименовывать без причины.
- Анимации — на CSS и небольшом отдельном JS (`js/reveal.js`, `js/slider.js`), без зависимостей от внешних библиотек.

## Соглашения по правкам
- Прежний вариант не удаляем: оставляем файл или комментарий «Откат: …» рядом с изменением.
- Правки клиента берём по датам, которые указывает заказчик.
- Работаем в отдельной ветке, в `main` без согласования не вливаем.
